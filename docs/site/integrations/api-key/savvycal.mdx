SavvyCal uses a long-lived API key. Authsome stores the key encrypted in the local vault, injects it at request time through the proxy, and keeps it out of shell history, process listings, and environment dumps.

## At a glance

| | |
|---|---|
| Provider name | `savvycal` |
| Display name | SavvyCal |
| Auth type | API key |
| Header | `Authorization: Bearer <key>` |
| Proxy host | `api.savvycal.com` |
| Env var | `SAVVYCAL_API_KEY` |
| Where to get a key | [https://savvycal.com/settings/developer](https://savvycal.com/settings/developer) |

## Get a key

Create an API key in the SavvyCal dashboard at [https://savvycal.com/settings/developer](https://savvycal.com/settings/developer).

## Log in

```bash
authsome login savvycal
```

A local browser form opens at `http://127.0.0.1:7998`. Paste the key into the masked input and submit.

<MaskedInputNote />

Verify:

```bash
authsome get savvycal --field status
# → connected
```

## Use the key

Run the agent under the proxy (recommended). 

<CodeGroup>

```bash Proxy (recommended)
authsome run -- python my_agent.py
```

```bash Environment
eval "$(authsome export savvycal --format env)"
echo $SAVVYCAL_API_KEY
```

</CodeGroup>

Under the proxy, authsome sets `SAVVYCAL_API_KEY=authsome-proxy-managed` in the child's environment and injects the real key into outbound requests to `api.savvycal.com`. The child process never sees the actual value.

## Multiple keys

<MultiConnectionsCta />

```bash
authsome login savvycal --connection personal
authsome login savvycal --connection team
```

## Rotate or remove the key

```bash
authsome login savvycal --force          # rotate
authsome logout savvycal                  # remove local credential
authsome remove savvycal                  # remove all local state for the provider
```

API-key providers have no revocation endpoint, so `revoke` and `remove` are equivalent for SavvyCal.

## Override the bundled definition

```bash
authsome inspect savvycal > ~/.authsome/providers/savvycal.json
# edit fields
authsome list   # source now shows "custom" for savvycal
```
