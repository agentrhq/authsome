Rewardful uses a long-lived API key. Authsome stores the key encrypted in the local vault, injects it at request time through the proxy, and keeps it out of shell history, process listings, and environment dumps.

## At a glance

| | |
|---|---|
| Provider name | `rewardful` |
| Display name | Rewardful |
| Auth type | API key |
| Header | `Authorization: Bearer <key>` |
| Proxy host | `api.getrewardful.com` |
| Env var | `REWARDFUL_API_KEY` |
| Where to get a key | [https://app.getrewardful.com/company/api-keys](https://app.getrewardful.com/company/api-keys) |

## Get a key

Create an API key in the Rewardful dashboard at [https://app.getrewardful.com/company/api-keys](https://app.getrewardful.com/company/api-keys).

## Log in

```bash
authsome login rewardful
```

A local browser form opens at `http://127.0.0.1:7998`. Paste the key into the masked input and submit.

<MaskedInputNote />

Verify:

```bash
authsome get rewardful --field status
# → connected
```

## Use the key

Run the agent under the proxy. The library tab is for embedding authsome inside a larger Python orchestrator.

<CodeGroup>

```bash Proxy (recommended)
authsome run -- python my_agent.py
```

```bash Environment
eval "$(authsome export rewardful --format env)"
echo $REWARDFUL_API_KEY
```

```python Python library
from authsome.server.dependencies import create_auth_service

auth = create_auth_service()
key = auth.get_access_token("rewardful", connection="default")
```

</CodeGroup>

Under the proxy, authsome sets `REWARDFUL_API_KEY=authsome-proxy-managed` in the child's environment and injects the real key into outbound requests to `api.getrewardful.com`. The child process never sees the actual value.

## Multiple keys

<MultiConnectionsCta />

```bash
authsome login rewardful --connection personal
authsome login rewardful --connection team
```

## Rotate or remove the key

```bash
authsome login rewardful --force          # rotate
authsome logout rewardful                  # remove local credential
authsome advanced remove rewardful                  # remove all local state for the provider
```

API-key providers have no revocation endpoint, so `revoke` and `remove` are equivalent for Rewardful.

## Override the bundled definition

```bash
authsome inspect rewardful > ~/.authsome/providers/rewardful.json
# edit fields
authsome list   # source now shows "custom" for rewardful
```

See [Provider schema](/reference/provider-schema) for every field.
