/goal There should extremely clear role of each module. The module of identity tells how an agent is identified and authenticated ( think it like openid + oauth ). The role of proxy is to become a proxy server that intercepts requests and injects credentials based on rules. The vault is the one that tells how to safely and securely save the credentials in a kv. The goal of audit is to keep a record of what is happening and where. The server is the application code that ties up identity + authentication + vault + audit. The proxy, ui and cli are client to this server. And so it should be like that. All the rlationships like vault is owned by principal should be server logic. Saving record of all available identities, vaults, or principals should be responsibility of server. Interacting with filesystem should be server.
